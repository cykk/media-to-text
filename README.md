## ✨ Key Features

- **Multi-Format Support**: Easily convert `MP3`, `MP4`, `WAV`, `M4A`, `MOV`, and `AAC` files into accurate text transcription.
- **AI-Powered Accuracy**: Built on OpenAI Whisper & Faster-Whisper models for reliable multi-lingual speech recognition.
- **Subtitle Generation**: Automatically generate and export synchronized `.srt` and `.vtt` subtitle files for video editing.
- **Privacy First**: Process files locally on your GPU/CPU without uploading data to third-party servers.
- **Batch Processing**: Transcribe large media folders or long-form audio/video files seamlessly.
